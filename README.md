# AnchorWorld project page

A responsive, static research project page for the CVPR 2027 submission. Open `index.html` in a browser or serve this folder with any static web server.

## Included assets

- `assets/paper.pdf` — submitted main paper
- `assets/supplementary.pdf` — submitted supplementary material
- `assets/anchorworld-teaser.png` — paper teaser and scene overview
- `assets/world-gallery.pdf` — qualitative gallery
- `assets/decoder-ablation.pdf` — decoder comparison
- `assets/structure-pilots.pdf` — sketch-guided structure examples
- `assets/teaser.pdf` — vector teaser figure

Author identity and code/model destinations are intentionally withheld while the submission is under double-blind review. Update the anonymized BibTeX and author note when preparing a public release.
